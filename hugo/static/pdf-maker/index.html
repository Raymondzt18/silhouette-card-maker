Riftbound PDF Proxy Maker

Upload card images and this page will lay them out into a print-and-cut PDF with registration marks for a Silhouette cutting machine, tailored for Riftbound (63 × 88 mm cards). Everything runs locally in your browser — your images are never uploaded anywhere.

Need card art? Grab it with the Piltover Archive or Riftmana decklist fetcher from the Riftbound plugin docs, then upload the images here.

0. Import missing cards (optional)

Paste a copied card list here — plain text (e.g. copied off a decklist/marketplace page showing "3 × $1.23" style quantities) or raw HTML both work. If the pasted HTML has card thumbnail images, their filenames are used as exact card codes automatically; otherwise names are looked up by name when you fetch.

Images come from the Piltover Archive CDN (the only card image source that allows fetching from a browser page like this one). Lines already written as a card code (like OGN-214) skip name lookup entirely and are more reliable; plain names are resolved via Riftmana's search, which may occasionally fail to be reachable from a browser — if a name fails, edit that line to use its card code instead and fetch again. Fetched cards are added to the Front images list below, alongside anything you upload manually.
